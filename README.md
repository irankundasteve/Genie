# Genie

Node.js + React (browser ESM) marketing site and API prototype for Genie.

## Run locally

```bash
npm run dev
```

Open http://localhost:3001 and navigate with hash routes:
- `#home`
- `#features`
- `#pricing`
- `#solutions`
- `#docs`
- `#blog`
- `#about`
- `#contact`
- `#status`
- `#auth`
- `#dashboard`
- `#builder`
- `#knowledge`
- `#integrations`
- `#logs`
- `#analytics`
- `#livechat`
- `#account`
- `#billing`
- `#privacy`
- `#terms`
- `#ethics`
- `#cookies`
- `#admin`
